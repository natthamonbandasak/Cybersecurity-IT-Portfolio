# Bash & Linux Automation

This folder contains shell scripts developed to automate routine system administration, task scheduling, and data processing in Linux environments.

## 📂 Included Scripts & Files

*   **`backup.sh`**: Automates the backup process of specified directories to ensure data availability and reduce manual administrative overhead.
*   **`crontab-schedule`**: Configuration file demonstrating the use of cron jobs to schedule and manage automated recurring tasks.
*   **`fc_accuracy.sh` & `fc_accuracyall.sh`**: Scripts designed to parse data, process inputs, and calculate accuracy metrics.
*   **`weekly_stats.sh`**: A reporting script used to aggregate, analyze, and display weekly statistical data.
*   **`rx_poc.sh`**: A proof-of-concept shell script focusing on automated data handling.

1. Navigate to the directory containing the script:
   ```bash
   cd Bash-Linux

2. Make the script executable:

3. Run the script:
