# Python Scripting & Data Handling

This repository contains Python scripts and automation projects developed to handle data processing, text parsing, and API interactions. These projects demonstrate my ability to programmatically manage and extract value from raw data.

## 🛠️ Core Skills Demonstrated

*   **Data Parsing & Regex:** Extracting and cleaning specific data points from raw text and log files using Regular Expressions.
*   **API Integration:** Retrieving, processing, and formatting data from external web APIs.
*   **Data Structures:** Utilizing lists, dictionaries, and tuples for efficient data organization and manipulation.
*   **Process Automation:** Writing conditional loops and scripts to automate repetitive data-handling tasks.

*(Note: These foundational projects were developed during the University of Michigan's "Python for Everybody" coursework.)*
