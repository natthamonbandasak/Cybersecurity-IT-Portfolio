# 🛡️ Cybersecurity Portfolio

## 📝 About This Repository
This repository contains a collection of cybersecurity projects, scripts, and documentation developed as part of the **Google Cybersecurity Professional Certificate**. The projects demonstrate practical skills in network security, threat analysis, automation, and security auditing.

---

## 💻 Scripts & Automation
The files in this section demonstrate programming and system administration skills for security:

*   **`update_allow_list.py`** 
    *   **Description:** Python algorithm to automatically read and update an IP address allow list (Importing and parsing a text file in a security-related scenario).
*   **`security_log_scanner.sh`**
    *   **Description:** Linux/Bash script to monitor access logs, manage file permissions, and verify file integrity (Using Linux commands to manage file permissions).
*   **`threat_investigation_queries.sql`**
    *   **Description:** SQL queries to search and filter database records for security incident investigation (Applying filters to SQL queries).
